# Capstone Project

RAG 기반 개인화 추천 시스템 구축 (캡스톤 프로젝트)

목적: 대규모 언어 모델(LLM)의 할루시네이션을 최소화하고 실시간 데이터를 반영한 신뢰 기반 추천 서비스 구현.

핵심 역할: 시스템 아키텍처 설계, 비정형 데이터 전처리 파이프라인 구축, RAG 로직 최적화.

기술적 도전:

Hybrid Retrieval(Semantic + Keyword)을 적용하여 검색 정확도 개선.

LangChain을 활용한 LLM 오케스트레이션 및 프롬프트 고도화.

Gradio 기반 인터랙티브 UI 구현으로 모델 성능 검증 환경 구축.

의의: 석사 과정에서 습득한 AI 이론을 실제 End-to-End 서비스로 구현하며 기술적 실현 가능성을 입증함.
